## 🚀 How to Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/GoelLakshay0511/PA_Class_Questions.git
   ```

2. **Navigate to any week's folder:**
   ```bash
   cd PA_Class_Questions/PA_Questions/"Week 10"
   ```

3. **Compile and run any Java file:**
   ```bash
   javac FileName.java
   java FileName
   ```
